# Task — FD-006 — Recurring meeting auditor

**Phase**: 14 | **Effort**: 2h | **Deps**: FD-001 | **Spec**: spec/focus-defense.md

## Goal
Quarterly review of recurring meetings: which to cancel, reduce frequency, or refocus.

## Acceptance criteria
- [ ] Quarterly cron (1st of quarter) identifies recurring meetings (≥ 4 occurrences in last 90d)
- [ ] For each: load past instances, action item count, attendee feedback if available
- [ ] Generate report: "X% had no actions, suggest cancel/reduce/refocus"
- [ ] Surfaces in proactive feed
- [ ] User accepts → drafts the cancel/modify actions through ActionExecutor
