# Task — LM-005 — SilentChannel (private user ↔ agent during call)

**Phase**: 13 | **Effort**: 4h | **Deps**: LM-004, CDS-001 | **Spec**: spec/live-meeting.md

## Goal
A private side-channel between user and their agent during the meeting. Only user sees it. Suggestions appear here. User can ask questions silently.

## Acceptance criteria
- [ ] Liveblocks room created per active meeting, scoped to userId
- [ ] React component `<SilentChannel meetingId={...}/>` renders chat-like panel
- [ ] Real-time push of LiveAnalyzer signals to user's device only
- [ ] User can type/speak question → answered by master orchestrator with full meeting context
- [ ] Pin-this-moment button → saves transcript range + note to memory
- [ ] Closes automatically when meeting ends, panel collapses
- [ ] Mobile-responsive (key: many users will have this on phone while in Zoom on laptop)
