# Task — A2A-003 — Negotiation primitives

**Phase**: 10 | **Effort**: 5h | **Deps**: A2A-002, AG-003

## Goal
proposeSlot / counterProposeSlot / acceptProposal flow with server-side state.

## Acceptance criteria
- [ ] `a2a_negotiations` table tracks proposals + timeline
- [ ] proposeSlot: creates negotiation, evaluates against own calendar, returns considering/rejected/accepted/counter
- [ ] counterProposeSlot: links to existing negotiation
- [ ] acceptProposal: creates calendar events on both sides via integrations
- [ ] State machine: open → considering → countered → accepted | rejected
- [ ] User approval gate: untrusted peers always require user approval before accepting
- [ ] Tests: full handshake flow, both successful and counter-rejected
