# Task — AG-001 — Master Orchestrator

**Phase**: 4
**Effort**: 6-8 hours
**Deps**: M-002, AI-001, ACT-001

## Goal

Implement the master orchestrator that handles user messages, recalls memory, routes to sub-agents via tool calls, streams responses.

## Acceptance criteria

- [ ] `packages/ai/agents/master/orchestrator.ts` exports `MasterOrchestrator` class
- [ ] `handle(input)` matches signature in spec
- [ ] Loads conversation history (last 10 turns) from DB
- [ ] Recalls relevant memories before responding
- [ ] System prompt versioned + loaded from `prompts/master/system.v1.md`
- [ ] Tool registry exposed: recallMemory, searchEmails, prepareMeeting, findPerson, proposeEmailDraft, scheduleEvent, rememberFact, forgetFact, webSearch, runCalculation, openDecisionFile
- [ ] Multi-step generation (max 10 steps)
- [ ] Streaming token output via AsyncIterable
- [ ] Tool calls visible in stream (so UI can show "thinking" states)
- [ ] After completion, conversation summary written to memory if salient (LLM judges salience)
- [ ] Voice mode variant uses shorter system prompt + 3-sentence cap
- [ ] Tests covering: simple Q&A, tool-calling, memory recall, voice mode, streaming

### Class skeleton

```typescript
export class MasterOrchestrator {
  constructor(
    private userId: string,
    private deps: {
      memory: MemoryOrchestrator;
      router: Router;
      db: Database;
      actionExecutor: ActionExecutor;
      subAgents: SubAgentRegistry;
    },
  ) {}

  async handle(input: HandleInput): Promise<AsyncIterable<OrchestratorEvent>> {
    const { message, conversationId, modality } = input;

    // 1. Load context
    const history = await this.loadHistory(conversationId, 10);
    const memories = await this.deps.memory.recall(message, { limit: 15 });

    // 2. Build system prompt
    const systemPrompt = await this.buildSystemPrompt({ memories, modality });

    // 3. Define tools
    const tools = this.buildTools();

    // 4. Run multi-step
    const stream = await this.deps.router.complete({
      agent: 'master',
      userId: this.userId,
      task: modality === 'voice' ? 'master-response-voice' : 'master-response',
      promptVersion: 'v1',
      input: {
        systemPrompt,
        messages: [...history, { role: 'user', content: message }],
        tools,
      },
      options: { stream: true },
    });

    // 5. Yield events as they arrive
    return this.processStream(stream, conversationId);
  }

  private async *processStream(stream: AsyncIterable<RouterChunk>, conversationId: string): AsyncIterable<OrchestratorEvent> {
    let fullText = '';
    const toolCalls: ToolCall[] = [];

    for await (const chunk of stream) {
      if (chunk.type === 'text') {
        fullText += chunk.text;
        yield { type: 'text', delta: chunk.text };
      } else if (chunk.type === 'tool_call') {
        toolCalls.push(chunk.tool);
        yield { type: 'tool_call_start', tool: chunk.tool };
      } else if (chunk.type === 'tool_result') {
        yield { type: 'tool_call_end', tool: chunk.tool, result: chunk.result };
      }
    }

    // 6. Persist message
    await this.persistMessage(conversationId, fullText, toolCalls);

    // 7. Salience check + memory write
    if (await this.shouldRemember(fullText, toolCalls)) {
      await this.summarizeAndRemember(conversationId);
    }

    yield { type: 'done', fullText, toolCalls };
  }

  private buildTools(): ToolRegistry {
    return {
      recallMemory: tool({
        description: 'Search user memory for relevant facts',
        parameters: z.object({ query: z.string(), limit: z.number().optional() }),
        execute: async ({ query, limit }) => {
          return await this.deps.memory.recall(query, { limit });
        },
      }),
      proposeEmailDraft: tool({
        description: 'Propose an email draft (user must approve to send)',
        parameters: z.object({ to: z.string(), subject: z.string(), body: z.string() }),
        execute: async (params) => {
          const action = await this.deps.actionExecutor.propose({
            userId: this.userId,
            type: 'email.send',
            payload: params,
            reasoning: 'User requested via conversation',
            context: { triggeredBy: 'user_request' },
          });
          return { actionId: action.id, status: action.status };
        },
      }),
      // ... other tools
    };
  }
}
```

### System prompt template (`prompts/master/system.v1.md`)

```markdown
You are {{agentName}}, personal Chief of Staff to {{userName}}.

You have deep memory of their work and life. You act on their behalf with integrity and full transparency.

# Relevant memory for this conversation:
{{#each memories}}
- [{{type}} | conf:{{confidence}}] {{content}}
{{/each}}

# Current context:
- Time: {{now}} ({{userTimezone}})
- Day: {{dayOfWeek}}
{{#if location}}- Location: {{location}}{{/if}}
- Inbox: {{unreadEmails}} unread, {{meetingsToday}} meetings today
- Active focus: {{activeFocus}}

# Your principles:
1. Be concise and action-oriented like a Chief of Staff. No flowery preamble.
2. Lead with the answer or action; explain only briefly why.
3. For state-changing actions, use propose* tools — do not act directly.
4. Cite which memory you used (UI will render the link).
5. If you need clarification, ask ONE focused question, not many.
6. Always be on {{userName}}'s side. Never optimize for third parties.
7. If unsure, say so. Do not bluff.

# Your tools:
{{toolList}}
```

### Voice variant (`prompts/master/system.voice.v1.md`)

Shorter, conversational, max 3 sentences output, no bullet points.

### Salience judge (`prompts/master/salience.v1.md`)

Given a conversation summary, judges if it contains a fact worth remembering.

```markdown
You judge whether this conversation contains information worth remembering long-term.

Conversation:
{{transcript}}

Output JSON:
{
  "shouldRemember": boolean,
  "factsToExtract": [{ "content": string, "type": "...", "entities": ["..."] }]
}

Remember-worthy:
- New facts about people in user's network
- Stated preferences
- Decisions and their reasoning
- Commitments made

Skip:
- Pleasantries
- Already-known facts
- Speculative musings without commitment
```

## Notes

- Streaming is critical — voice mode requires sub-200ms first token
- Tools must always return structured JSON, never raw text
- Tool execution should be parallel-safe (e.g. multiple memory recalls)
- Conversation persistence happens after stream completes, not during
