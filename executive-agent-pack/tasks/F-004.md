# Task — F-004 — packages/shared (errors, types, env)

**Phase**: 0 | **Effort**: 1-2h | **Deps**: F-001, F-003 | **Spec**: spec/env-vars.md

## Goal

Shared utilities: typed errors, common types, env validation, hashing utils.

## Acceptance criteria

- [ ] `packages/shared/src/env.ts` validates env vars with zod, fails fast at boot
- [ ] `packages/shared/src/errors.ts` exports typed error classes (RouterError, MemoryError, ActionError, IntegrationError, AuthError) all extending base `AppError`
- [ ] `packages/shared/src/hash.ts` exports `hashStr`, `hashJson` (SHA-256 hex)
- [ ] `packages/shared/src/result.ts` exports `Result<T,E>` type + helpers (`ok`, `err`, `unwrap`)
- [ ] `packages/shared/src/id.ts` exports `newId(prefix)` — generates `prefix_<nanoid>` IDs
- [ ] `packages/shared/src/datetime.ts` exports tz-aware date utils
- [ ] All exports from `packages/shared/src/index.ts`
- [ ] Tests for env validation, hashing, errors

```typescript
import { z } from 'zod';

const schema = z.object({
  NODE_ENV: z.enum(['development', 'staging', 'production']).default('development'),
  APP_URL: z.string().url(),
  DATABASE_URL: z.string().url(),
  DIRECT_DATABASE_URL: z.string().url().optional(),
  ANTHROPIC_API_KEY: z.string().min(1),
  OPENAI_API_KEY: z.string().min(1),
  CLERK_SECRET_KEY: z.string().min(1),
  CLERK_WEBHOOK_SECRET: z.string().min(1),
  INNGEST_EVENT_KEY: z.string().min(1),
  INNGEST_SIGNING_KEY: z.string().min(1),
  UPSTASH_REDIS_REST_URL: z.string().url(),
  UPSTASH_REDIS_REST_TOKEN: z.string().min(1),
  LANGFUSE_PUBLIC_KEY: z.string().min(1),
  LANGFUSE_SECRET_KEY: z.string().min(1),
  LANGFUSE_HOST: z.string().url().default('https://cloud.langfuse.com'),
  SENTRY_DSN: z.string().url().optional(),
  DB_COLUMN_ENCRYPTION_KEY: z.string().length(64),
  DEFAULT_USER_DAILY_BUDGET_CENTS: z.coerce.number().default(300),
  HARD_LIMIT_MULTIPLIER: z.coerce.number().default(1.2),
  // ... full list per spec/env-vars.md
});

export const env = schema.parse(process.env);
export type Env = z.infer<typeof schema>;
```

### `errors.ts`
```typescript
export class AppError extends Error {
  constructor(public code: string, message: string, public cause?: unknown) {
    super(message);
    this.name = this.constructor.name;
  }
  toJSON() { return { code: this.code, message: this.message }; }
}
export class RouterError extends AppError {}
export class MemoryError extends AppError {}
export class ActionError extends AppError {}
export class IntegrationError extends AppError {}
export class AuthError extends AppError {}
export class BudgetError extends AppError {}
```
