# Task — P-001 — Pattern detector

**Phase**: 8 | **Effort**: 5h | **Deps**: M-005 | **Spec**: spec/proactive.md

## Goal
Nightly per-user pattern detection: action patterns, energy patterns, communication patterns, decision patterns, network patterns.

## Acceptance criteria
- [ ] Inngest cron `detectPatterns` per-user at 02:00 user-local
- [ ] Each detector reads from raw_items, memories, decisions, ai_calls
- [ ] Persists to `user_patterns(userId, type, key, value, confidence, observationCount)`
- [ ] Decay: pattern not re-observed in 30d → confidence -10
- [ ] Tests: synthetic dataset producing known patterns
