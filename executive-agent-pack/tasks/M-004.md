# Task — M-004 — Entity extractor (NER, cached, LLM-backed)

**Phase**: 1 | **Effort**: 3h | **Deps**: M-001, AI-001

## Goal
Extract entities (people, companies, projects, places, topics) from text and link to existing entities or propose new ones.

## Acceptance criteria
- [ ] `EntityExtractor.extract(text, userId)` returns `{ matched: Entity[], proposed: NewEntity[] }`
- [ ] Two-stage: fast literal name match (regex/Aho-Corasick) → if 0 matches, fallback to LLM NER (haiku)
- [ ] Cache 24h on (text hash + entity set hash)
- [ ] Confidence threshold for auto-create new entity: 80
- [ ] Proposed entities below threshold → return for human review (no auto-insert)
- [ ] Coreference resolution: "him", "her", "the company" resolved using conversation context (when conv-aware variant invoked)
- [ ] Tests: known person mentioned by full name; ambiguous "Anna" resolves to most-recent; unknown name → proposed
