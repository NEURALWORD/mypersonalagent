# Task — I-005 — LinkedIn enrichment

**Phase**: 3 | **Effort**: 3h | **Deps**: M-001

## Goal
Enrich person entities with LinkedIn data (title, company, recent posts) via Proxycurl/RapidAPI or direct API.

## Acceptance criteria
- [ ] On entity creation/update, queue enrichment job (rate-limited, 100/day default)
- [ ] Provider abstraction: swap Proxycurl, RapidAPI, etc.
- [ ] Cache enrichment 30d
- [ ] Update entity attributes with: title, company, location, headline, recent posts, last activity
- [ ] User can disable enrichment per-entity or globally
- [ ] Tests: provider mock, cache, opt-out enforcement
