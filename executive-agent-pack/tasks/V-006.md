# Task — V-006 — Cross-device handoff

**Phase**: 7 | **Effort**: 3h | **Deps**: V-001, CDS-001

## Goal
User starts conversation on phone, walks to desk; continues on desktop seamlessly.

## Acceptance criteria
- [ ] Conversation state in Redis: `voice:session:{userId}` (turn history, scratchpad, pending tools)
- [ ] All user devices attach to same LiveKit room
- [ ] New device connect → subscribes to current state via Liveblocks
- [ ] Audio hand-off: previous device fades out, new device fades in (3s crossfade)
- [ ] Tests: simulate two clients, verify handoff
