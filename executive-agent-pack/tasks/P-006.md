# Task — P-006 — Email autopilot mode

**Phase**: 8 | **Effort**: 5h | **Deps**: AG-002, ACT-004

## Goal
User configures "respond automatically in my voice for emails matching X". Fully autonomous response within rules.

## Acceptance criteria
- [ ] Setting per category/sender: 'autopilot_send' | 'autopilot_draft' | 'manual'
- [ ] Autopilot pipeline: classify → if matches autopilot rule → draft → send (auto-approve)
- [ ] Always logs to audit, surfaces summary in daily digest
- [ ] Hard guards: never autopilot first email from new sender, never autopilot threads with > 2 hops complexity, never autopilot if subject contains keyword like "URGENT", "lawsuit", "investor"
- [ ] User can review autopilot decisions in dashboard, mark "shouldn't have" → adjusts weights
- [ ] Tests: rule matching, guard triggering, audit completeness
