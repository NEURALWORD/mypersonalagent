# Task — LM-006 — Post-call synthesizer

**Phase**: 13 | **Effort**: 5h | **Deps**: LM-003, LM-004, ACT-001 | **Spec**: spec/live-meeting.md

## Goal
Within 60 seconds of meeting end, produce: summary, action items, follow-up email drafts, decision file proposals, person memory updates.

## Acceptance criteria
- [ ] `Synthesizer` class triggered on `meeting-ended` event
- [ ] Uses full transcript + LiveAnalyzer signals as input
- [ ] Outputs structured `MeetingPackage`: summary, actions, drafts, decisionProposals, peopleUpdates
- [ ] Memory writes are atomic (transactional)
- [ ] Follow-up email drafts go through ActionExecutor (require user approval before send)
- [ ] Decision proposals create draft decision files (user opens or dismisses)
- [ ] Latency: ≤ 60s from meeting-ended to package available
- [ ] Eval: action item precision ≥ 0.85, recall ≥ 0.80 on golden set
