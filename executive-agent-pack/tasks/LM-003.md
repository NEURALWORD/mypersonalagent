# Task — LM-003 — Streaming STT + diarization pipeline

**Phase**: 13 | **Effort**: 6h | **Deps**: LM-001, V-002 | **Spec**: spec/live-meeting.md

## Goal
Real-time transcript with speaker labels, fed from MeetingJoiner audio stream.

## Acceptance criteria
- [ ] `STTPipeline` class consumes audio stream, emits `transcript-chunk` events
- [ ] Each chunk has: text, speakerLabel, startMs, endMs, confidence
- [ ] Whisper streaming used; diarization via Whisper word-level + speaker embedding
- [ ] Lag ≤ 2 seconds from speech to chunk emitted
- [ ] Persisted to `meeting_transcripts` table per chunk (append-only)
- [ ] Memory pressure capped: rolling 5-min buffer in memory, older flushed to DB
- [ ] Handles silences gracefully (no spurious empty chunks)
- [ ] Eval: word-error-rate ≤ 0.10 on 10 sample meetings
