# Task — LM-004 — LiveAnalyzer (real-time signals)

**Phase**: 13 | **Effort**: 6h | **Deps**: LM-003 | **Spec**: spec/live-meeting.md

## Goal
Every 30s window of transcript → analyze for: unanswered questions to user, action items, decisions, network mentions, emotional signals.

## Acceptance criteria
- [ ] `LiveAnalyzer` class consumes transcript chunks, emits `signal` events
- [ ] Window: 30s rolling
- [ ] Signal types: `question_to_user_unanswered`, `action_item_proposed`, `decision_in_progress`, `person_mentioned`, `sentiment_shift`
- [ ] Each signal has: type, confidence, transcriptRange, suggestedAction
- [ ] Uses Sonnet for fast classification with structured output
- [ ] Deduplication: same signal not emitted twice within 60s
- [ ] Eval against 10 hand-labeled meeting recordings, F1 ≥ 0.70 per signal type
- [ ] Cost cap: ≤ $0.20 per hour of meeting analyzed
