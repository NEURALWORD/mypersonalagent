# Task — F-003 — TypeScript strict + path aliases

**Phase**: 0 | **Effort**: 30 min | **Deps**: F-001

## Goal

Configure TypeScript strict mode and path aliases (`@exec/*`) usable across all packages.

## Acceptance criteria

- [ ] `tsconfig.base.json` at root with strict + target ES2022 + bundler resolution
- [ ] Each package has `tsconfig.json` extending base
- [ ] Path aliases work: `import { x } from '@exec/db'`, `@exec/ai`, `@exec/shared`, etc.
- [ ] `pnpm typecheck` passes across all packages
- [ ] `noUnusedLocals`, `noUnusedParameters`, `noImplicitOverride`, `noFallthroughCasesInSwitch` all true
- [ ] `noUncheckedIndexedAccess` true (forces array bounds checks)

## Implementation

`tsconfig.base.json`:
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noImplicitOverride": true,
    "noUncheckedIndexedAccess": true,
    "noFallthroughCasesInSwitch": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "resolveJsonModule": true,
    "isolatedModules": true,
    "verbatimModuleSyntax": true,
    "baseUrl": ".",
    "paths": {
      "@exec/db": ["./packages/db/src"],
      "@exec/db/*": ["./packages/db/src/*"],
      "@exec/ai": ["./packages/ai/src"],
      "@exec/ai/*": ["./packages/ai/src/*"],
      "@exec/shared": ["./packages/shared/src"],
      "@exec/shared/*": ["./packages/shared/src/*"],
      "@exec/integrations/*": ["./packages/integrations/*/src"],
      "@exec/jobs": ["./packages/jobs/src"],
      "@exec/actions": ["./packages/actions/src"],
      "@exec/ui": ["./packages/ui/src"],
      "@exec/protocols": ["./packages/protocols/src"]
    }
  }
}
```

Each package `tsconfig.json`:
```json
{ "extends": "../../tsconfig.base.json", "include": ["src/**/*"] }
```
