# Task — ACT-004 — Permission rules engine

**Phase**: 5 | **Effort**: 4h | **Deps**: ACT-001

## Goal
Auto-approve / always-ask / auto-reject rules with JSON-logic conditions. Fast in-memory cache per user.

## Acceptance criteria
- [ ] `permission_rules` table with conditions JSON
- [ ] Rule evaluator using `json-logic-js` or equivalent
- [ ] Cache: per-user rule set in memory, invalidated on rule change
- [ ] UI to view/edit rules
- [ ] Conflict resolution: most-specific match wins; explicit `always_ask` overrides any auto-approve
- [ ] Suggested rules surfaced after 3 similar approvals ("Auto-approve emails matching <pattern>?")
- [ ] Tests: rule matching, conflict resolution, suggestion logic
