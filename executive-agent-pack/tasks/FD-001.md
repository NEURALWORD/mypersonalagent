# Task — FD-001 — ROIScorer engine

**Phase**: 14 (Focus Defense) | **Effort**: 5h | **Deps**: AG-003, M-002 | **Spec**: spec/focus-defense.md

## Goal
Score every upcoming meeting (next 14d) on ROI: low/medium/high with reasoning.

## Acceptance criteria
- [ ] `ROIScorer.score(event, context)` returns `{ score: 'low'|'medium'|'high', reasoning: string, signals: {...} }`
- [ ] Inputs: calendar event, attendee memories, meeting outcome history, user role+priorities
- [ ] Heuristic + LLM hybrid: heuristics filter obvious cases, LLM for ambiguous
- [ ] Daily cron (06:00 user time) re-scores upcoming 14d, persists to `meeting_roi_scores` table
- [ ] User-override learning: when user marks score wrong, signal stored, baseline adjusted
- [ ] Eval: ≥ 0.75 agreement with user labels on 100-meeting calibration set
- [ ] Cost: ≤ $0.05 per meeting scored
