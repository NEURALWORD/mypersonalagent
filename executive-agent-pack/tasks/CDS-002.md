# Task — CDS-002 — Conversation continuity state machine

**Phase**: 9 | **Effort**: 3h | **Deps**: CDS-001, AG-001

## Goal
State machine that lets a conversation resume seamlessly across devices.

## Acceptance criteria
- [ ] Per-conversation: state in Liveblocks (active turn, pending tool, partial response, scratchpad)
- [ ] On device switch: new device subscribes, hydrates UI from state
- [ ] If LLM call in flight: stream resumes on new device (LLM call kept server-side)
- [ ] Tests: simulated device switch mid-stream, mid-tool-call
