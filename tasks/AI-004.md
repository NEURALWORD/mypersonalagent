# Task — AI-004 — Eval harness foundation

**Phase**: 2 | **Effort**: 4h | **Deps**: AI-001 | **Spec**: spec/evals.md

## Goal
Vitest-based eval runner with fixture loading, LLM-as-judge utilities, baseline diffing, three tiers.

## Acceptance criteria
- [ ] `packages/ai/evals/runner.ts` exports `runEval(suite, options)`
- [ ] Fixture loader: JSON in `eval/fixtures/<task>.json` with schema validation
- [ ] LLM judge: `judgeBy(criteria, input, output, rubric)` using Opus, 3x averaging, structured output
- [ ] Pairwise: `pairwiseJudge(a, b, cases)` returns winner + per-case reasoning
- [ ] Latency benchmarks: `benchLatency(fn, cases, iterations)` returns p50/p95/p99
- [ ] Baseline I/O: `loadBaseline(task)` / `writeBaseline(task, results)`
- [ ] Diff: `diffBaseline(current, baseline)` returns regressions/improvements
- [ ] CLI: `pnpm eval:unit`, `pnpm eval:integration`, `pnpm eval:regression`
- [ ] Cost cap per run with kill switch
