# Task — W-001 — Anonymized event aggregation

**Phase**: 11 | **Effort**: 5h | **Deps**: M-005, F-005 | **Spec**: spec/wisdom.md

## Goal
Weekly pipeline: extract per-user features, anonymize, aggregate by cohort, apply DP noise, write to wisdom_aggregates.

## Acceptance criteria
- [ ] Inngest weekly cron Sun 02:00 UTC
- [ ] Step 1: pull data for users with `wisdom_opt_in=true`
- [ ] Step 2: extract features per pattern type (decision_outcome, time_allocation, etc.)
- [ ] Step 3: strip PII (no names, no specific entities — only aggregated stats per cohort)
- [ ] Step 4: group by cohort_signature, drop cohorts n<50
- [ ] Step 5: compute mean/median/p75 + apply Laplace noise (ε=1.0, sensitivity computed per metric)
- [ ] Step 6: write to wisdom_aggregates (versioned by date)
- [ ] Step 7: discard intermediate per-user features
- [ ] Tests: privacy guarantees (DP epsilon math), k-anonymity (n≥50), no PII leakage
