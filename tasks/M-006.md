## Goal
Golden dataset for memory recall + eval harness integration.

## Acceptance criteria
- [ ] `eval/fixtures/memory-recall.json` with ≥200 hand-curated cases (queries, expected memories, distractors)
- [ ] Fixture loader for tests
- [ ] `eval/unit/memory-recall.test.ts`:

  - Precision@5 ≥ 0.70

- [ ] Hooked into `pnpm eval:unit`

- [ ] Baseline saved to `eval/baselines/memory-recall.json` after first green run
