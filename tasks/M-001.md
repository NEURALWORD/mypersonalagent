**Phase**: 1 | **Effort**: 2h | **Deps**: F-005 | **Spec**: spec/memory-layer.md, spec/database.md

## Goal
Add `entities`, `relationships`, `memories`, `memory_links`, `raw_items` tables to Drizzle schema. Indexes including HNSW.

## Acceptance criteria
- [ ] Schema files in `packages/db/src/schema/memory.ts` exporting all 5 tables
- [ ] Vector column type: `vector(1536)` (use `pgvector` Drizzle types or raw)
- [ ] Migration generated + applied
- [ ] HNSW index on `entities.embedding` and `memories.embedding` with `vector_cosine_ops`, `m=16`, `ef_construction=64`
- [ ] B-tree indexes per spec/database.md
- [ ] FTS index `memories_fts` (gin tsvector) for fallback search
- [ ] Seed script generates 100 sample memories for dev
- [ ] Tests: insert+query+delete on each table with cascade
