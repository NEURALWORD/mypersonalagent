Inngest cron at 03:00 user-local. Cluster episodic memories per entity, generate semantic summary, drop expired.

## Acceptance criteria
- [ ] Inngest function `consolidateMemories` scheduled per-user via cron expression with user TZ offset

- [ ] Step 3: insert summary, link via `memory_links.linkType='consolidates'`, mark sources `consolidated_at`
- [ ] Step 4: drop memories with `expiresAt < now`
- [ ] Step 5: recompute importance for top 100 entities
- [ ] Idempotent: re-running same day is no-op
- [ ] Cost target: < $0.10/user/run on average
- [ ] Tests: cluster detection, summary quality (LLM judge ≥ 4/5), idempotency
