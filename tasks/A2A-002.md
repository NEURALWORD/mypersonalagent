# Task — A2A-002 — Agent endpoint exposure

**Phase**: 10 | **Effort**: 4h | **Deps**: A2A-001

## Goal
Expose user's agent at predictable HTTPS endpoint with signed responses.

## Acceptance criteria
- [ ] `GET /.well-known/agent.json` per user (route `/agent/[did]/.well-known/agent.json`)
- [ ] `POST /agent/[did]/a2a/v1` JSON-RPC dispatcher
- [ ] Methods registered: ping, getCapabilities, proposeSlot, counterProposeSlot, acceptProposal, requestIntroduction, notify
- [ ] Per-user agent identity: keypair generated on signup, private key encrypted at rest
- [ ] Trust policy enforced per peer DID (a2a_peers table)
- [ ] Tests: end-to-end ping between two test agents
