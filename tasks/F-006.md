# Task — F-006 — Next.js app skeleton

**Phase**: 0 | **Effort**: 2h | **Deps**: F-001, F-003 | **Spec**: claude.md

## Goal

`apps/web` Next.js 15 (App Router) + Tailwind v4 + shadcn/ui foundation.

## Acceptance criteria

- [ ] `apps/web/` Next.js 15 with App Router, React 19, TS strict
- [ ] Tailwind v4 with custom theme tokens (colors, font, spacing)
- [ ] shadcn/ui CLI initialized; install Button, Card, Dialog, Sheet, Input, Textarea, Toast, Skeleton, Avatar
- [ ] Layout with sidebar (skeleton, no logic yet) + main + right pane
- [ ] Dark mode default (per executive aesthetic)
- [ ] Routes: `/` (landing), `/app` (auth-gated layout), `/app/chat`, `/app/inbox`, `/app/calendar`, `/app/people`, `/app/settings`
- [ ] Loading states + error boundaries on all routes
- [ ] `pnpm dev:web` starts on port 3000
- [ ] Lighthouse mobile FCP < 1.5s on landing

## Implementation

```bash
cd apps
pnpm create next-app@latest web --typescript --tailwind --app --src-dir --import-alias "@/*"
cd web
pnpm dlx shadcn@latest init
pnpm dlx shadcn@latest add button card dialog sheet input textarea sonner skeleton avatar dropdown-menu
```

Theme tokens (CSS vars):
- Background: near-black (#0a0a0b) for shell, #111114 for cards
- Primary: emerald 500-ish (calm, trust)
- Accent: cool magenta (Manuel's palette signal — `#e33178`-adjacent)
- Font: Inter for UI, Geist Mono for code, system serif for long-form
