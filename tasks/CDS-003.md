# Task — CDS-003 — Notification fanout

**Phase**: 9 | **Effort**: 3h | **Deps**: CDS-001

## Goal
Web Push + email + SMS fanout based on per-user channel preferences.

## Acceptance criteria
- [ ] Web Push setup (VAPID keys, service worker)
- [ ] Email via Resend (transactional)
- [ ] SMS via Twilio (high-urgency only)
- [ ] Channel routing logic: urgency × user pref × Do Not Disturb hours
- [ ] Deduplication: same proactive item not delivered twice (read tracking)
- [ ] Tests: routing logic with various pref combos
