# Task — F-002 — Docker compose for local services

**Phase**: 0
**Effort**: 30 min
**Deps**: F-001
**Spec**: spec/database.md

## Goal

Local development services: Postgres 16 with pgvector + Redis.

## Acceptance criteria

- [ ] `docker-compose.yml` at root
- [ ] Postgres 16 with pgvector extension auto-installed
- [ ] Redis 7
- [ ] Persistent volumes
- [ ] `docker compose up -d` brings up both
- [ ] `docker compose down` clean shutdown
- [ ] Init script creates DB and enables pgvector + pgcrypto

## Implementation

### `docker-compose.yml`

```yaml
version: "3.9"

services:
  postgres:
    image: pgvector/pgvector:pg16
    container_name: exec-agent-postgres
    environment:
      POSTGRES_USER: dev
      POSTGRES_PASSWORD: dev
      POSTGRES_DB: exec_agent_dev
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./scripts/db-init.sql:/docker-entrypoint-initdb.d/init.sql:ro
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U dev"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: exec-agent-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 5

volumes:
  postgres_data:
  redis_data:
```

### `scripts/db-init.sql`

```sql
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
```

## Test

```bash
docker compose up -d
docker exec exec-agent-postgres psql -U dev -d exec_agent_dev -c "SELECT extname FROM pg_extension;"
# expect: vector, pgcrypto, uuid-ossp listed
docker exec exec-agent-redis redis-cli ping
# expect: PONG
```

## Notes

For prod use Supabase managed Postgres with pgvector enabled (no Docker needed).
