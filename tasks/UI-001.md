# Task — UI-001 — Chat workspace

**Phase**: 6 | **Effort**: 6h | **Deps**: AG-001, F-008

## Goal
Streaming chat with tool-call visibility, memory citations, message actions.

## Acceptance criteria
- [ ] Chat route at `/app/chat` and `/app/chat/[conversationId]`
- [ ] Streaming via tRPC subscription or SSE
- [ ] Tool calls rendered as collapsible cards ("Searching memory...", "Drafting email...")
- [ ] Memory citations rendered as inline chips with hover preview
- [ ] Message actions: copy, regenerate, edit, branch
- [ ] Scroll-to-bottom + keyboard shortcuts (cmd+enter to send, cmd+shift+v to voice)
- [ ] Empty state: 4 suggested prompts based on time of day
- [ ] Performance: typing → first token rendered < 1.5s
