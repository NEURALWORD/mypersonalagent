# Task — L-001 — Onboarding flow (5 min to value)

**Phase**: 12 | **Effort**: 5h | **Deps**: F-007, I-001, I-003

## Goal
First-run onboarding that gets user from zero to a "wow" moment within 5 minutes.

## Acceptance criteria
- [ ] Step 1 (1 min): connect Gmail + Calendar (skip-able but discouraged)
- [ ] Step 2 (1 min): cohort attributes (role, stage, etc.) — used for wisdom
- [ ] Step 3 (1 min): backfill begins; loading screen shows progress + stat counters
- [ ] Step 4 (1 min): agent name + voice selection
- [ ] Step 5 (1 min): first conversation pre-seeded with 3 valuable insights from backfilled data
- [ ] "Wow moment": agent surfaces something the user did not know (e.g. "I noticed you have 12 unanswered emails from past quarter from people in your network")
- [ ] Tests: full onboarding flow, skip paths
