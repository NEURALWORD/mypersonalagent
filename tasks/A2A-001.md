# Task — A2A-001 — Protocol spec implementation

**Phase**: 10 | **Effort**: 4h | **Deps**: F-008 | **Spec**: spec/a2a-protocol.md

## Goal
JSON-RPC 2.0 dispatcher with Ed25519 signature verification, DID resolution, replay protection.

## Acceptance criteria
- [ ] `packages/protocols/a2a/` with: server, client, signing, did-resolver
- [ ] DID method `did:web` resolution: fetches `/.well-known/agent.json`, caches public key 1h
- [ ] Signature: Ed25519 over canonical(method + params + timestamp + nonce)
- [ ] Replay protection: nonce cache 1h, timestamp window ±5min
- [ ] JSON-RPC 2.0 wire format compliant
- [ ] Tests: signature roundtrip, replay rejection, expired timestamp rejection
