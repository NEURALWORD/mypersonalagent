# Task — F-001 — Initialize monorepo

**Phase**: 0 (Foundations)
**Estimated effort**: 1-2 hours
**Dependencies**: none
**Spec references**: claude.md (folder layout)

## Goal

Set up Turborepo monorepo with pnpm workspaces, Biome for lint+format, base TypeScript config.

## Acceptance criteria

- [ ] Repo at root has `package.json`, `pnpm-workspace.yaml`, `turbo.json`, `tsconfig.base.json`, `biome.json`
- [ ] Folder structure as in `claude.md` exists (apps/, packages/)
- [ ] `pnpm install` runs without errors
- [ ] `pnpm typecheck` runs (passes trivially with no code)
- [ ] `pnpm lint` runs (passes trivially)
- [ ] `pnpm format` formats code with Biome
- [ ] `.gitignore` excludes node_modules, .env*, dist/, .next/, .turbo/, .cache/
- [ ] README.md at root with one-line description + link to claude.md

## Implementation steps

1. `pnpm init` at root
2. Create `pnpm-workspace.yaml`:
   ```yaml
   packages:
     - "apps/*"
     - "packages/*"
   ```
3. Install root dev deps: `pnpm add -Dw turbo @biomejs/biome typescript`
4. Create `turbo.json`:
   ```json
   {
     "$schema": "https://turbo.build/schema.json",
     "pipeline": {
       "build": { "dependsOn": ["^build"], "outputs": [".next/**", "dist/**"] },
       "dev": { "cache": false, "persistent": true },
       "typecheck": { "dependsOn": ["^typecheck"] },
       "lint": {},
       "test": { "dependsOn": ["^build"] },
       "eval": {},
       "gate": { "dependsOn": ["typecheck", "lint", "test"] }
     }
   }
   ```
5. Create `biome.json` with strict rules + tabs for indent + 100 line width
6. Create `tsconfig.base.json` with strict mode + paths
7. Create empty folders for apps/ and packages/ subdirectories with `.gitkeep`
8. Add scripts to root package.json:
   ```json
   "scripts": {
     "dev": "turbo dev",
     "build": "turbo build",
     "typecheck": "turbo typecheck",
     "lint": "biome check .",
     "format": "biome format --write .",
     "test": "turbo test",
     "eval": "turbo eval",
     "gate": "turbo gate"
   }
   ```
9. Initial git commit

## Test
