# Task — ACT-003 — Audit log + viewer

**Phase**: 5 | **Effort**: 3h | **Deps**: ACT-001

## Goal
Searchable history of all actions + audit_log events. CSV export for compliance.

## Acceptance criteria
- [ ] `audit_log` table partitioned by month, retained 7 years
- [ ] UI route `/app/audit` with filters (date range, action type, status, agent)
- [ ] Each entry: actor, event, action context, payload diff
- [ ] CSV export endpoint: signed URL, 1-time download
- [ ] Tamper-evidence: hash chain (each entry includes hash of previous) — verifies integrity
- [ ] Tests: chain verification, export correctness
