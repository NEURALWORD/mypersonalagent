# Task — ACT-001 — ActionExecutor

**Phase**: 5 | **Effort**: 6h | **Deps**: F-005 | **Spec**: spec/actions.md

## Goal
Propose / approve / execute / revert state machine. Per-action-type executors.

## Acceptance criteria
- [ ] `ActionExecutor` class with: `propose`, `approve`, `reject`, `revert`, `listPending`, `getHistory`
- [ ] State machine enforced (illegal transitions throw)
- [ ] Per-type executors registered: email.send, email.archive, email.label, calendar.create, calendar.update, calendar.delete, memory.create, memory.update, memory.delete, intro.send, task.create, doc.edit
- [ ] Each executor has `execute()` and `revert()` impl
- [ ] Idempotency keys = action id; re-execute is no-op
- [ ] Audit log entry per state change
- [ ] Inngest job runs `execute` after approval (durable)
- [ ] Revert window scheduled via Inngest delayed event
- [ ] Tests: full flow per action type, race condition double-approve, revert after window expires
