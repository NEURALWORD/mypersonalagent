# Task — P-002 — Anticipation engine

**Phase**: 8 | **Effort**: 5h | **Deps**: P-001

## Goal
Trigger sources (cron, event, pattern, context-shift) → candidate generator → filter+rank → surface.

## Acceptance criteria
- [ ] Trigger handlers: cron events, raw_items inserts, calendar deltas, location/time shifts
- [ ] Each trigger calls candidate generators (per type) producing `ProactiveCandidate[]`
- [ ] Filter: predicted value threshold, dedup vs last 7d, user prefs
- [ ] Rank: value × confidence × (1 - fatigue)
- [ ] Cap per channel: push 3/day, chat 10/day
- [ ] Surface via channel: chat (insert into conversation), push (Web Push API), digest (email)
- [ ] Learning loop: track viewed/acted/dismissed; feedback into next ranking
