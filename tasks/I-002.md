# Task — I-002 — Gmail ingester

**Phase**: 3 | **Effort**: 4h | **Deps**: I-001, M-003

## Goal
Inngest function: on `gmail.message.received`, fetch message, normalize to `raw_items`, extract entities, write memories where salient.

## Acceptance criteria
- [ ] On event, fetch message via Gmail API (headers + body, no attachments yet)
- [ ] Normalize: `RawEmail { id, threadId, from, to, cc, subject, body, date, headers }`
- [ ] Insert into `raw_items` with idempotency on (source, externalId)
- [ ] Extract entities (M-004) and create/link
- [ ] Salience filter (cheap haiku call) decides if memory write needed
- [ ] If salient: write `episodic` memory, tag entities, attach source link
- [ ] PII never logged outside Langfuse traces
- [ ] Tests: end-to-end with sample emails, idempotency, salience filter
