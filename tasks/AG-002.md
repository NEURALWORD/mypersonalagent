# Task — AG-002 — Email Agent

**Phase**: 4 | **Effort**: 6h | **Deps**: AG-001, I-002 | **Spec**: spec/agents.md

## Goal
EmailAgent: classify, draft, summarize, extract action items. User-voice modeling.

## Acceptance criteria
- [ ] `classifyEmail(emailId)` returns priority (P0-P3) + category + suggestedAction
- [ ] `draftReply(emailId, instructions?)` returns draft in user voice
- [ ] `summarizeThread(threadId)` returns bullet summary
- [ ] `extractActionItems(emailId)` returns typed list
- [ ] User-voice profile: builds after 100 sent emails ingested; 20-sample style block + descriptors fed to draft prompt
- [ ] Update style profile monthly via Inngest cron
- [ ] All tools registered with master orchestrator
- [ ] Eval suite per task with golden datasets (≥50 cases each)
- [ ] Cost: classify < $0.005/email, draft < $0.02/email
