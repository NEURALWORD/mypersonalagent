**Phase**: 13 (Live Meeting) | **Effort**: 4h | **Deps**: AG-001 | **Spec**: spec/live-meeting.md

## Goal

## Acceptance criteria
- [ ] `packages/live-meeting/joiner.ts` exports `MeetingJoiner` interface
- [ ] Methods: `join(meetingUrl, options)`, `leave()`, `isInMeeting()`, `getAudioStream()`, `postMessage(text)`
- [ ] Stub implementation for development (`MockJoiner`)
- [ ] Event emitter: `audio-chunk`, `participant-joined`, `participant-left`, `meeting-ended`
- [ ] Unit tests for MockJoiner
- [ ] Type-safe options: `{ identifyAs: string, recordingDisclosureMessage: string, jurisdictionMode: 'one-party' | 'two-party' }`
