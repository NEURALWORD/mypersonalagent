# Task — WB-005 — ConversationRunner with strict prompt eval

**Phase**: 15 | **Effort**: 5h | **Deps**: WB-004, AI-003 | **Spec**: spec/wellbeing.md

## Goal
Generate the actual messages the agent sends to user about wellbeing. THE MOST SENSITIVE PROMPT IN THE PRODUCT.

## Acceptance criteria
- [ ] Prompts in `prompts/wellbeing/` versioned (yellow.v1, orange.v1, red.v1, checkin.v1)
- [ ] Always includes: specific data, no generic warnings, "I'm an AI not a clinician" disclaimer for red
- [ ] Eval suite: 50 hand-crafted scenarios, human-judged on respectfulness, specificity, helpfulness, non-preachiness
- [ ] Promotion gate: human eval ≥ 4.2/5 average across 4 dimensions
- [ ] No release without 5+ design partners signing off on tone
- [ ] Critical: user can dismiss any wellbeing message with one click; agent does not double down
