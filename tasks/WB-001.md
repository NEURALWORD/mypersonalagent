# Task — WB-001 — SignalCollector

**Phase**: 15 (Wellbeing) | **Effort**: 4h | **Deps**: I-001, I-003 | **Spec**: spec/wellbeing.md

## Goal
Passive aggregation of wellbeing signals from existing data sources. No surveys.

## Acceptance criteria
- [ ] `SignalCollector` runs hourly, computes for current 24h window:
  - first_activity_time, last_activity_time
  - email_volume_sent, email_volume_received
  - email_response_latency_p50
  - meeting_hours, meeting_count
  - late_night_email_count (after 22:00)
  - weekend_activity_count
- [ ] Stores in `wellbeing_signals` table (encrypted at rest, user-only key)
- [ ] No cross-tenant aggregation in any code path (lint rule enforced)
- [ ] Excluded from wisdom layer aggregations (assertion in W-001)
- [ ] Opt-out check first: if disabled, returns early without computing
