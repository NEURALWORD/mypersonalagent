# Task — V-004 — Voice orchestrator

**Phase**: 7 | **Effort**: 5h | **Deps**: V-002, V-003, AG-001

## Goal
End-to-end voice loop. Sub-600ms first-token. Interruption handling.

## Acceptance criteria
- [ ] On `voice.utterance.finalized` → master orchestrator (voice mode)
- [ ] LLM streaming → Cartesia streaming, parallel
- [ ] Interruption: `user_started_talking` event cancels TTS, agent stops, picks up new input
- [ ] Tool calls during voice: speak "let me check that" while running in parallel
- [ ] Total latency p95 ≤ 600ms (per spec)
- [ ] Eval: 50 sample utterances, latency benchmark
