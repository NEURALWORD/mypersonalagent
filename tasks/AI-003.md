# Task — AI-003 — Prompt registry (versioned)

**Phase**: 2 | **Effort**: 3h | **Deps**: AI-001

## Goal
Hot-reloadable, versioned prompt library. A/B testing support.

## Acceptance criteria
- [ ] Prompts live as Markdown files in `packages/ai/prompts/<agent>/<task>.v<n>.md`
- [ ] Loader: `loadPrompt(path, version)` returns `{ system, fewShots, schema, tokensEstimated }`
- [ ] Mustache-style `{{var}}` interpolation with strict missing-var error
- [ ] Active version per task in DB table `prompt_versions(task_key, active_version, rollout_percent)`
- [ ] Per-user A/B routing via stable hash on userId
- [ ] Hot reload in dev (chokidar watching `prompts/` directory)
- [ ] Tests: interpolation, missing var error, A/B split distribution
