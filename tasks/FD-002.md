# Task — FD-002 — Deep work guardian

**Phase**: 14 | **Effort**: 4h | **Deps**: I-003, FD-001 | **Spec**: spec/focus-defense.md

## Goal
Auto-create + protect deep work blocks on user's calendar based on preferences.

## Acceptance criteria
- [ ] User preferences stored in `focus_preferences` table (deep_work_hours, max_meeting_hours_per_day, recovery_buffer_min, no_meeting_days)
- [ ] Cron (Sunday evening): generate next-week deep work blocks, create on calendar via I-003
- [ ] Block title: "🔒 Deep work — Manuel" (configurable)
- [ ] Block visibility: busy (not free)
- [ ] When meeting invite arrives that conflicts: trigger ProactiveCandidate "decline or move?"
- [ ] User can override → agent learns → reduces aggressiveness
- [ ] Tests: block placement logic, conflict detection, override learning
