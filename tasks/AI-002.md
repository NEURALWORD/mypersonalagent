# Task — AI-002 — Token budget enforcer

**Phase**: 2 | **Effort**: 2h | **Deps**: AI-001 | **Spec**: spec/ai-router.md

## Goal
Per-user daily/monthly budget tracking + soft warnings + hard limit + admin override.

## Acceptance criteria
- [ ] `Budget` class with `checkOrThrow(userId)`, `charge(userId, cents)`, `getStatus(userId)`
- [ ] Atomic upsert into `user_daily_budget` (no race conditions)
- [ ] Soft warning at 70%: emits PostHog event + sets UI banner flag
- [ ] Hard limit at 100%: returns degraded response (haiku-only + cache-only)
- [ ] Block at 120%: throws `BudgetError`
- [ ] Admin endpoint to raise/reset budget for a user
- [ ] Bypass flag for critical tasks (memory recall, action revert)
- [ ] Tests: concurrent charges (race), exact-threshold transitions, bypass behavior
